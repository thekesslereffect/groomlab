# Fonts

`GoogleSansFlex-latin.woff2`: Google Sans Flex by Google, the latin subset of the variable font
(weight 1-1000, optical size), as Google Fonts serves it. Licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org/open-font-license-official-text/).
It is in the repository so the site's build never fetches it (`app/layout.tsx`).
